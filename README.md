# NextStop：雙北公車即時看板

給通勤用的手機版公車到站看板，涵蓋台北市與新北市公車，資料來自交通部 TDX 運輸資料流通服務。

**線上版本**：https://bookman117.github.io/NextStop/

## 功能

- **搜尋**：輸入路線號碼或站牌名稱的一部分，同時查詢台北與新北。路線在本機的路線清單裡找，不花 API 額度；只有輸入含中文時才向 TDX 查站牌。
- **常用**：在路線頁按 ☆ 收藏「路線＋站牌」，或在站牌頁收藏整個站牌看板；首頁依到站時間排序。
- **路線頁**：列出每一站的到站倒數與車牌，可切換去程與返程。
- **站牌看板**：列出經過該站的所有路線，並標示行駛方向。
- **營運狀態**：顯示尚未發車、交管不停靠、末班車已過、今日未營運，以及末班車標記。
- **到站提醒**：3 分鐘內變色；1 分鐘內改成紅底閃爍「進站中」。
- **自動更新**：每 60 秒更新一次，頁面切到背景時暫停。
- **地圖**：地圖鋪滿整個畫面，列表浮在上面。路線頁顯示路線、站牌與公車位置；點列表的站，地圖會移過去，點地圖上的站，列表會捲到該站。常用頁顯示收藏的站牌，站牌看板顯示站牌位置。
- **定位**：地圖右上的 ◎ 會顯示你的位置；在路線頁會自動選取這條路線上離你最近的站。搜尋頁的「附近的站牌」會列出 400 公尺內的站牌與距離。
- **選取的站**：在路線頁選了站之後，標題下方會固定顯示這一站的到站時間，抽屜收起時也看得到；點一下會捲回列表中的該站。
- **手機版**：列表在底部抽屜，可拖曳或點把手切換三段高度（只露標題／一半／幾乎滿版）。搜尋與設定頁會自動展開。
- **桌面版**（寬度 1024px 以上）：列表是左側浮動面板，分頁列移到面板上方。
- **深色模式**：跟隨系統設定，地圖底圖也會跟著變暗。
- **離線開啟**：加入主畫面後，沒有網路也能打開介面、看到常用清單與看過區域的地圖；到站時間需要連線，恢復連線後會自動更新。
- **網址與返回**：每個畫面都有自己的網址，例如 `#route/Taipei/262/0` 是 262 去程。手機的返回手勢會回到上一個畫面；常用的路線也可以直接加入書籤或主畫面。

## 開始使用

1. 用手機開啟上方網址。沒有填金鑰時，頁面會顯示示範資料（虛構的 307 路線）。
2. 到 [TDX 註冊會員](https://tdx.transportdata.tw/register)，審核通過後在會員中心「資料服務 › API 金鑰」建立一組金鑰。
3. 在看板的「設定」分頁貼上 Client ID 與 Client Secret，按「儲存並測試連線」。
4. 加入主畫面：iOS Safari 點「分享 › 加入主畫面」；Android Chrome 點選單中的「安裝應用程式」或「加到主畫面」。之後會以 NextStop 圖示、全螢幕（沒有網址列）開啟。

## TDX 免費方案的限制

免費的基礎會員每把金鑰每分鐘最多 5 次，每月約 4,500 次（3 點，每 1,500 次折 1 點）。看板每 60 秒更新一次，一個畫面大約每分鐘 1 到 2 次；搜尋路線不花額度，第一次開某條路線會多 1 到 2 次（站序與線形，之後快取）。超過時畫面會顯示「等待 TDX 配額」並自動排隊。

每月額度大約夠一直開著看 35 到 40 小時。「設定」頁會顯示這台裝置本月的呼叫次數，達 80% 時頁面頂端會出現提醒。用量超過 105% 時，TDX 會停用帳號到月底，所以不要讓看板整天開在前景。實際用量以 TDX 會員中心的「使用統計」為準。

## 金鑰與隱私

- 金鑰只存在你這台裝置的瀏覽器 `localStorage`，頁面只會把它送往 `tdx.transportdata.tw`。
- 程式碼裡沒有任何金鑰，所以 repository 公開不會洩漏你的金鑰。
- 每個裝置與瀏覽器各自儲存金鑰和收藏；換手機或換瀏覽器需要重新填寫。
- 在「設定」按「清除金鑰」即可刪除這台裝置上的金鑰與 access token。
- 位置只有在你按 ◎ 或「附近的站牌」時才會取得，不會儲存。按 ◎ 時位置只在這台裝置使用；按「附近的站牌」時，會把你所在位置周圍約 400 公尺的經緯度範圍放進查詢送給 TDX。

## 技術說明

- **單一檔案**：`index.html` 內含 HTML、CSS 與 JavaScript，沒有建置步驟與相依套件。
- **驗證**：以 OAuth 2.0 client credentials 向 TDX 取得 access token，快取到過期前一分鐘。
- **使用的 TDX 端點**（`/api/basic/v2/Bus/`）：
  - `EstimatedTimeOfArrival/City/{City}`：到站時間
  - `RealTimeNearStop/City/{City}`：車輛目前所在站與車牌
  - `StopOfRoute/City/{City}`：路線站序
  - `Route/City/{City}`、`Stop/City/{City}`：搜尋路線與站牌
- **流量控制**：所有請求依序排隊，任一 61 秒內最多送出 5 次，同一瀏覽器的分頁共用計數；換頁後還沒送出的舊請求會取消。收到 HTTP 429 時，等到配額恢復再重試一次。
- **快取**：台北與新北的路線清單、路線站序（含站牌座標）與路線線形存在瀏覽器裡 7 天，重開同一路線不必再呼叫 API。
- **地圖**：用 [Leaflet](https://leafletjs.com/) 1.9.4（cdnjs，附 SRI 雜湊）與內政部國土測繪中心的臺灣通用電子地圖灰階版（WMTS，免金鑰），讓路線與公車比底圖醒目。路線線形來自 TDX `Shape`，會沿著道路畫；在到站資料之後於背景載入，拿到之前先用站牌連線。公車畫在 `RealTimeNearStop` 回報的站牌位置，精度到「站」，地圖不會增加每輪更新的呼叫次數。Leaflet 載入失敗時，頁面退回原本的單欄列表。

## 檔案

- `index.html`：整個看板（HTML、CSS、JavaScript）。
- `manifest.webmanifest`、`icon.svg`、`icons/`：加入主畫面用的名稱與圖示。
- `sw.js`：service worker。頁面先抓網路、離線時用快取；Leaflet 與圖示用快取；地圖圖磚最多快取 400 張；TDX API 不經過快取。

## 本機開發

直接用瀏覽器開啟 `index.html` 即可，沒有金鑰時會使用示範資料。要測試真實資料，在「設定」填入金鑰。

部署方式是 GitHub Pages，從 `main` 分支根目錄發布；push 到 `main` 後約一分鐘生效。

## 已知限制

- 真實 TDX 資料在部分畫面的欄位顯示尚未完整實測，包括站牌看板的「往 ○○」、末班車標記與車牌。
- 用量計數只算這台裝置；在其他裝置或用同一組金鑰的其他程式呼叫的次數不會算進來。
- 地圖上的公車位置是「最近停靠或即將到達的站」，不是 GPS 即時位置。
- 2026-11-17 之前收藏的站牌沒有座標，不會出現在常用頁的地圖上；重新收藏一次即可。

## 資料來源

公車動態資料由[交通部 TDX 運輸資料流通服務](https://tdx.transportdata.tw/)提供。地圖底圖由[內政部國土測繪中心](https://maps.nlsc.gov.tw/)提供。
